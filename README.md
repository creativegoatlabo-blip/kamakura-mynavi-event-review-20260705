# マイナビイベント振り返り

2026年7月5日の鎌倉彫金工房の出展結果を説明する、社内共有用の静的HTMLです。

## データ

- 見学予約11組、実来店8組、見学キャンセル3組、成約3組。
- 成約3組は、2026年9月5日の担当者報告と制作記録をもとに集計。
- 来店からの成約率37.5％、予約からの成約率27.3％。
- 計画上の50％は「見学予約→成約」の仮説。インタラクティブな計算は実績ではありません。
- 出典の説明はページ下部に掲載。お客様・社員の氏名、個別住所、連絡先、原票は公開しません。

## 公開

GitHub Pagesで配信します。HTMLのrobots / googlebotメタタグは `noindex, nofollow, noarchive` です。検索除外はアクセス制限ではなく、URLで閲覧可能です。robots.txtでクロールを拒否するとnoindexを読めなくなるため、クロール拒否は設定していません。

## 動作

ビルド不要。index.html、tokens.css、styles.css、app.jsを同じフォルダで配信します。外部通信はGoogle Fontsのみで、アクセス解析・外部送信はありません。JavaScriptが無効でも、結果・説明・初期計算値を読めます。動きを減らす設定と印刷に対応しています。
